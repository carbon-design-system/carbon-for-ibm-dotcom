# Carbon for IBM.com Type Styles

Carbon for IBM.com builds upon Carbon's typography system by providing targeted
customizations and brand-expressive additions optimized for digital marketing
and editorial experiences on IBM.com.

## Usage in Component Styles

Import the type module wrapper from `@carbon/ibmdotcom-styles` instead of from
`@carbon/styles`:

```scss
@use '@carbon/ibmdotcom-styles/scss/globals/type' as *;
```

Then apply styles using the `type-style` mixin:

```scss
// Fluid tokens (responsive scaling across breakpoints)
.my-fluid-heading {
  @include type-style('fluid-heading-05', true);
}

// Fixed tokens (non-responsive)
.my-fixed-heading {
  @include type-style('heading-04');
}
```

## Available Type Styles

### C4D tokens

- <cds-tag type="purple">Custom</cds-tag> Core Carbon type tokens overridden
  with custom font sizes, line heights, breakpoints, or weights for IBM.com.
- <cds-tag type="green">Unique</cds-tag> Type tokens exclusive to
  `@carbon/ibmdotcom-styles`.
